# 415V-LT-Distribution-with-DG-Changeover
Electrical Single Line Diagram (SLD) of a 415V LT Distribution System with 45 kVA DG Backup, including load calculations, circuit protection and equipment selection.
Single Line Diagram – Electrical Engineering Project

Project Overview

This project presents a 415V Low Tension (LT) electrical power distribution system with utility supply and a 45 kVA Diesel Generator (DG) backup.

The system is designed for a typical small commercial building. It includes a main distribution busbar, circuit breakers, an automatic or manual changeover arrangement, and separate outgoing feeders for different electrical loads.

The purpose of this project is to demonstrate basic electrical distribution design, load calculation, equipment selection and AutoCAD drafting skills.

1. Project Details

- Project Name: 415V LT Distribution with DG Changeover
- System Voltage: 415V
- Supply: 3-Phase, 4-Wire, 50Hz
- Utility Supply: 415V
- DG Capacity: 45 kVA
- Changeover: 100A, 4-Pole ATS / Changeover Switch
- Main MCCB: 100A
- Main Busbar: 125A Copper
- Drawing Scale: NTS
- Drawing Revision: Rev A
- Drawing Date: 05-11-2026

2. Load Summary

- Total Connected Load: 46.5 kW
- Diversity Factor: 0.7
- Maximum Demand: Approximately 32.5 kW
- Power Factor: 0.9
- Maximum Demand Current: Approximately 50A
- DG Capacity: 45 kVA

3. Electrical Distribution

The main distribution system consists of six outgoing feeders.

- F1: Lighting and Fan Distribution – 6 kW
- F2: Power Socket Distribution – 10 kW
- F3: Air Conditioning – 18 kW
- F4: Pump Motor – 7.5 kW (10 HP)
- F5: Office and UPS – 5 kW
- F6: Spare Feeder for Future Expansion

7. Design Assumptions and Limitations
